# AI Content Agent Pro

وكيل لإنتاج الفيديوهات من النصوص تلقائياً.

## الحالة الحالية

هذا المستودع هو نقطة بداية للمشروع. لم يتم بعد نشر التطبيق أو ربط مزودي توليد الصور والصوت والفيديو.

## الخطة

- واجهة عربية مناسبة للهاتف (PWA).
- استقبال النصوص وتقسيمها إلى مشاهد.
- طابور مهام إنتاج ومتابعة الحالة.
- موصلات اختيارية لمزودي الصور والصوت والفيديو.
- تجميع الأصول وإخراج MP4 قبل مراجعة المستخدم.

## الملفات

سيتم رفع ملفات الواجهة ومحرك المهام على مراحل، ثم إعداد النشر والاستضافة.

## الأمان

لا تضع مفاتيح API أو كلمات المرور داخل المستودع. استخدم متغيرات البيئة والأسرار في منصة الاستضافة.
