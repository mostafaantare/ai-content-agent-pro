# AI Content Agent Pro

مشروع أولي لوكيل إنتاج محتوى فيديو من الاسكربت، بواجهة عربية قابلة للتثبيت كتطبيق PWA ومحرك مهام خلفي.

## ما يعمل في هذه النسخة
- واجهة ويب عربية لإرسال الاسكربت.
- API محمي برمز Bearer لإنشاء المهام ومتابعتها.
- طابور Redis/BullMQ وعامل خلفي.
- تقسيم أولي للمشاهد محلياً، أو تحليل المشاهد عبر OpenAI عند إضافة مفتاح API.
- PWA shell أساسي.

## ما لا يعمل بعد
هذه النسخة **لا تولّد صوراً أو صوتاً أو فيديو، ولا تنتج MP4 نهائياً**. يلزم اختيار وربط مزودي هذه الخدمات، كتابة موصلات تنزيل الأصول، وإضافة خطوة مونتاج فعلية وإشعارات وتخزين ملفات قبل اعتبارها مكتملة.

## التشغيل
1. انسخ `.env.example` إلى `.env` وضع `APP_TOKEN` عشوائياً قوياً. أضف `OPENAI_API_KEY` اختيارياً.
2. شغّل `docker compose up --build -d`.
3. انشر مجلد `web/` على استضافة HTTPS ثابتة، واجعل رابط API متاحاً عبر HTTPS.
4. أدخل رابط API ورمز الوصول في الواجهة.

## الأمان
- لا ترفع ملف `.env` ولا مفاتيح API إلى GitHub.
- استخدم HTTPS، وغيّر `APP_TOKEN` إلى قيمة عشوائية طويلة.
- أضف حدود استخدام ومصادقة مستخدمين وتخزيناً آمناً قبل الاستخدام العام.

## الحالة
Starter/MVP تقني، وليس خدمة مستضافة أو منتجاً نهائياً. لا توجد حالياً مفاتيح مزودي توليد أو استضافة مفعّلة.
