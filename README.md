# AI Content Agent Pro

واجهة عربية قابلة للتثبيت على الموبايل مع API بسيط لتجهيز خطة مشاهد من الاسكربت.

## النشر المجاني التجريبي
استخدم Render Blueprint من ملف `render.yaml` في جذر المستودع. سينشئ:
- API يعمل كـ Docker Web Service.
- واجهة PWA كـ Static Site.

يتم إنشاء `APP_TOKEN` تلقائياً بواسطة Render. انسخه من Environment في خدمة API وأدخله في الواجهة، مع رابط API.

## التشغيل المحلي
```bash
npm install
APP_TOKEN=change-me npm start
```

## الموجود حالياً
- استقبال الاسكربت والتحقق من طوله.
- تقسيم محلي إلى مشاهد مع نص تعليق ووصف بصري.
- تحليل اختياري عبر OpenAI عند ضبط `OPENAI_API_KEY`.
- متابعة حالة المهمة وتصدير خطة JSON من استجابة API.
- واجهة PWA قابلة للتثبيت.

## حدود النسخة الحالية
هذه نسخة MVP وليست وكيل إنتاج فيديو مكتمل: لا تنشئ صوراً أو صوتاً أو فيديو MP4، ولا تنشر تلقائياً. يلزم ربط مزودي توليد الصور والصوت والفيديو وإضافة المونتاج والتخزين والنشر. التخزين الحالي للمهام داخل ذاكرة الخدمة، لذلك قد تختفي المهام عند إعادة تشغيل خدمة Render المجانية.
